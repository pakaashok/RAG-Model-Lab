# Backstage Developer Portal

## What is Backstage?
Backstage is an open source developer portal
created by Spotify. It centralizes all your
infrastructure tooling services and documentation
in one place for developers.

## Core Features

### Software Catalog
- Central registry of all services
- Track ownership and metadata
- Discover existing components
- Component types:
  * Service backend or frontend
  * Website public facing sites
  * Library reusable code
  * Pipeline CI CD workflows
  * Infrastructure cloud resources
  * Documentation TechDocs

### TechDocs
- Documentation as code
- Write docs in Markdown
- Auto generates documentation site
- Versioned with code
- Uses MkDocs under the hood
- Supports diagrams
- Search functionality

### Software Templates
- Self service for developers
- Create new services and repos
- Standardize best practices
- Scaffolder templates
- Reduces onboarding time
- Enforces standards

### Plugins
- Extend Backstage functionality
- Available plugins:
  * GitHub Actions
  * ArgoCD
  * Kubernetes
  * PagerDuty
  * SonarQube
  * Jenkins
  * AWS services
  * Harness
  * Terraform
  * Datadog
  * Prometheus

## Backstage Architecture

### Components
1. Frontend React application
2. Backend Node.js application
3. Database PostgreSQL
4. Plugins additional features
5. Auth authentication providers

### Catalog Entity Example

apiVersion: backstage.io/v1alpha1
kind: Component
metadata:
  name: my-service
  description: My microservice
  tags:
    - nodejs
    - aws
  annotations:
    github.com/project-slug: org/repo
spec:
  type: service
  lifecycle: production
  owner: team-devops
  system: payment-system

### Entity Kinds
1. Component - Software units
2. API - Service APIs
3. Resource - Infrastructure
4. System - Group of components
5. Domain - Business domain
6. Group - Team or organization
7. User - Individual users
8. Location - Where entities are

## Backstage Setup

### Prerequisites
- Node.js 18 or higher
- Yarn package manager
- Docker for local development
- PostgreSQL database
- Git

### Installation Steps
1. Install Node.js
2. Create Backstage app using npx
3. Configure app-config.yaml
4. Add integrations
5. Setup authentication
6. Deploy to Kubernetes

### Configuration File
app-config.yaml contains:
- App metadata
- Backend configuration
- Database settings
- Auth providers
- Integrations
- Plugin configuration
- CORS settings
